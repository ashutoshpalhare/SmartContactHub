# Contact Form Plugin

Build a personal & startup subscription spend tracker called PulseLedger with category budgets, recurring billing alerts, CSV export, monthl... (inspired by Sukhendu2002/Contact-Form-Plugin)

Reference: https://github.com/Sukhendu2002/Contact-Form-Plugin

Requires PHP 8.1+ with pdo_sqlite and mbstring. Run `php -S localhost:8000` then open http://localhost:8000.
